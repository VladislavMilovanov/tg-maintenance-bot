## Идея проекта

**Для кого:**  
Для сотрудников предприятия и инженеров, ответственных за работу оборудования.

**Задача:**  
Помогать быстро понимать текущее состояние оборудования на основе данных мониторинга.

**Что умеет бот в первой версии:**  
- Простым языком объясняет состояние оборудования.
- Отвечает на вопросы о конкретной машине.
- Помогает понять, есть ли признаки проблемы (например, с подшипником).
- Даёт краткую оценку ситуации без технических терминов.

**Польза с первого дня:**  
- Быстрая ориентация по состоянию оборудования.
- Снижение рисков за счёт своевременного внимания к проблемам.
- Прозрачная и понятная картина для сотрудников.

**Примеры вопросов к боту:**
- Что сейчас с этим оборудованием?
- Какая ситуация по этой машине?
- Есть ли проблема с подшипником?
- Насколько критично текущее состояние?
- Что означает рост вибрации?
- Требуется ли внимание прямо сейчас?
