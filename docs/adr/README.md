# ADR проекта

ADR (Architecture Decision Record) фиксируют ключевые архитектурные решения проекта, их контекст, альтернативы и последствия.

---

## Принципы ведения ADR

- Фиксируем только значимые и долгоживущие архитектурные решения.
- Один ADR — одно решение и явный статус (`Proposed`, `Accepted`, `Superseded`, `Deprecated`).
- Каждый ADR содержит: контекст, альтернативы, решение, обоснование и последствия.
- ADR неизменяем по смыслу после принятия; при изменении решения создаётся новый ADR с ссылкой на предыдущий.
- Формат имён: `adr-XXX-short-name.md` (например, `adr-001-database.md`).
